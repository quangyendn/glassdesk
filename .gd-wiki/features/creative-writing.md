The `creative-writing` skill activates when the user wants prose to sound human, warm, or less like AI. It works for English and Vietnamese requests alike.

## When It Activates

The skill triggers on any request to write, draft, compose, edit, or rewrite prose — blog posts, essays, newsletters, emails, social media posts, captions, stories, or scripts. It also activates on Vietnamese cues such as *"viết tự nhiên hơn"*, *"đỡ giống AI"*, *"viết bài"*, *"soạn email"*, or *"biên tập lại"*.

It does NOT activate for code generation, code review, debugging, data analysis, or purely factual technical reference.

## Five-Step Process

| Step | Action |
|------|--------|
| 1 | Understand the content: purpose, intended tone, audience |
| 2 | Write with a human rhythm — vary sentence length deliberately |
| 3 | Strip AI tells: remove stock transitions, over-explaining, generic vocabulary |
| 4 | Add emotional depth — let the writing feel lived-in |
| 5 | Read it back as if speaking to a friend; soften anything cold or distant |

## Common AI Tells Removed

- Stock transitions: *furthermore*, *moreover*, *additionally*, *in addition*, *to summarize*
- Restating the obvious or repeating the topic sentence in a closing summary
- Uniform sentence length (the most reliable AI tell)
- Abstract nouns (*synergy*, *leverage*, *optimization*) where a concrete verb suffices
- Ornate dashes and colons used as a default rhythm device
